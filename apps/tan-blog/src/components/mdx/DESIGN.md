# 文章元件設計原則：「紙上之物」

整個站是一張四季信箋（晝）／一片夜空（夜讀）。文章裡的每個區塊——程式碼、提示、分頁、圖表——
都當成「放在這張紙上的東西」：一方另貼的箋、一行眉批、一張夾進來的相片。
新增或修改 `renderers/` 底下的元件時，照下面六條走；樣式集中在 `styles.css` 的「文章區塊」段落。

## 1. 一張紙，一種墨

- 只用主題 token：墨（`--foreground`）、朱（`--ink`，唯一的強調色）、玉（`--jade`）、
  紙（`--card` / `--muted`）。不寫 `blue-500`、`bg-amber-50` 這類 Tailwind 原色。
- 語意色（提示／成功／警告／危險）統一走 `--tone`：在 `[data-tone]` 上定義一個低彩度 oklch，
  底色、邊線、圖示都由它 `color-mix` 出來，晝夜各一組。四季換紙色時語意色不用跟著改。

## 2. 用髮絲線分層，不靠粗框和陰影

- 區塊邊界一律 1px `--block-rule`；層次靠「紙色上加幾 % 墨」做出來（`--block-surface`）。
- 陰影只留給真的「浮在紙上」的東西（圖片、拍立得）。程式碼、提示框都是貼平的。

## 3. 同一副骨架

```
┌ 題簽 ─────────────────────────── 工具 ┐   ← .mdx-block-head：小字、muted，左標籤右操作
│ 內容                                  │   ← .mdx-block-body
└ 註腳（可選：展開、說明、計數）────────┘
```

- 外距 `my-8`、圓角 `--block-radius`（8px，跟圖片同）、內距 1rem／1.25rem。
- 題簽用 `--font-mono`（技術資訊：語言、檔名、模板）或文楷（人話：標題、說明）。
- 區塊互相巢狀時（例如分頁裡放程式碼）內層去掉外框，不出現框中框。

## 4. 內容優先，工具退後

- 複製、換行、執行等按鈕平時淡（muted），滑過區塊或鍵盤聚焦時才清楚；觸控裝置一律顯示。
- 操作的結果就地回饋（按鈕變「已複製」），不另外跳 toast。

## 5. 動作要輕

- 過場 150–300ms、ease-out；只動 opacity／transform／高度。
- `prefers-reduced-motion: reduce` 時關掉位移與長條動畫。

## 6. 讀得到、按得到

- 語意標籤（`figure`、`blockquote`、`role="note"`）、按鈕都有可讀名稱（走 Paraglide 三語）。
- 焦點用朱色 `--ring`；文字對比至少 WCAG AA；CJK 不用斜體。
