## 一句話

**墨與水，加一點朱；其他時候，紙上只有字。**

整站只有一件會動的事：墨碰到水。進站時一滴墨落下、被水沖淡（開場）；首頁是一片可以滴墨的水面；換頁時字像墨碰到水一樣暈開、再收乾。除此之外，所有頁面都是紙、字和一點朱。

## 0. 元素預算

整站只有這幾樣東西：

| 元素 | 在哪裡 |
|---|---|
| **紙** | 所有頁面的底。晝是宣紙色，夜是燈下的深藍黑 |
| **五階墨** | 字、線、淡淡的層次 |
| **朱** | 唯一的強調色：目前所在、滑過、落款 |
| **墨暈**（墨碰到水） | 只在四處：進站開場、首頁的水面、換頁的墨洇、打開導覽的墨點（2026-10-29 站主加的） |
| **鳥居**（唯一的物件，2026-10-30 站主選定） | 只在首頁首屏（水面、筆跡模式），水墨畫法、用朱；素面沒有 |
| **筆跡**（墨落在紙上） | 只在首頁的「筆跡」模式（2026-11-03 起是首頁預設）：游標當筆寫出、幾秒乾掉的墨（2026-10-30 站主要求保留 demo 的「一筆」）；同時在首頁的人看得到彼此寫，登入的人寫的乾了留一層淡乾痕到當天結束（2026-11-03） |
| **筆的顏料**（2026-11-03 站主要的） | 只給首頁筆跡的筆：墨、朱，加赭墨、赭石、藤黃、汁綠、石綠、花青六種國畫顏料（畫得出枝幹、葉、苔），彩度壓低；不進一般 UI |
| **皺紙**（揉過又攤開的紙，2026-11-02 站主要的例外） | 只在想法頁最新那一則的底（`thinking/-components/crumpled-paper.tsx`）：一片片紙色上平塗的淡墨小面＋極淡的摺痕，不用光影、陰影、漸層 |
| **乾筆線**（一筆寫到乾，2026-11-02） | 只在時光頁每一年的左邊（`timeline/-components/brush-line.tsx`）：一個節氣一筆，寫得多就飽黑、寫得少就乾細露飛白；每篇一個書法的「、」；捲到才由上往下寫出來。同一套筆法另有一處：首頁首屏以下的**円相**（2026-11-03 站主定案；見第 5 節），一年寫成一個圓 |
| **游絲**（乾筆線的延伸，2026-11-03 站主照概念圖選的，等站主看） | 只在友鏈（`friends/-components/friend-list.tsx`、`yousi.ts`）：一排一筆橫貫的細墨，穿過那一排每顆圓頭像的中心，兩端拉到版面外；粗細只慢慢變（有幾處按下去、兩端提筆），線本身要順，不加手抖、不繞圈。排法是普通格子（一排三欄／窄版兩欄），頭像上下錯開一點，線是量好頭像位置後才畫，所以名字再長、人再多都撐得住 |
| **朱印**（2026-11-02 站主要的） | 只在文章／日記內頁：文首的分類印、文末作者的名印、讀者蓋的印（蓋印＝按讚）。白文方印或朱框，不另做其他印 |

- **要加任何新元素，先拿掉一樣**，並且給站主看過。元素預算是這份文件最重要的一條。
- 除了首頁的鳥居，不放任何物件或場景：不畫山水、建築、庭園、神社物件、文具、照片框，也不用聊天 App 的樣式。
- 「拿掉題材之後，它是不是只用紙、墨、朱畫出來的？」不是就不做。

## 1. 材料

| 材料 | token | 規則 |
|---|---|---|
| 紙 | `--background` | 只有這一種底，不另開卡片底色。紙紋是事先畫好的纖維圖（`public/paper-fiber.svg`，`scripts/paper-fiber.mjs` 產生）當 mask、用前景墨（晝 7%、夜 6%），固定在視窗不跟著捲（styles.css `body::before`）；不用即時算的 SVG 濾鏡（曾經害手機捲動卡住） |
| 墨 | `--ink-1` … `--ink-5`（由 `--foreground` 混 `--background`，100／80／64／38／13%） | 1 標題內文、2 摘要次要、3 日期 meta（小字過 AA）、4 只做裝飾、5 髮絲線 |
| 朱 | `--zhu` | 夜裡用提亮的朱，不另開顏色（燈的暖黃停用） |
| 節氣色 | `--season` | 只給墨暈引擎的 accent 用（開場墨流邊緣的一抹），不進一般 UI |

- 沒有陰影、漸層、毛玻璃、擬真材質（例外只有想法頁的皺紙，而且也只用紙與淡墨）。層次靠濃淡和留白；真的要分隔時用 `--ink-5` 的髮絲線。
- **卡片**（2026-11-03 站主放寬）：一個「獨立的東西」可以包成卡片——一位朋友、一個表單、一個彈窗或工具列，自己是一個可以點的單位、要跟周圍分開的。做法：紙色或極淡的墨底（`--ink-5` 那一階）＋ `--ink-5` 髮絲線框、小圓角，滑過框轉淡朱；仍然不用陰影、漸層、毛玻璃。列表的「一列」不用卡片（文章、日記、時光照舊是字的列），卡片不疊卡片。
- 中文不加粗表現強調，用朱或字距。

## 2. 字

| 語系 | 標題／人話 | 內文 |
|---|---|---|
| zh-Hant | 霞鶩文楷 TC | Noto Serif TC |
| ja | Klee One（文楷的原型） | Noto Serif JP |
| en | Newsreader | Newsreader |

- 字型 token 依 `<html lang>` 切換，元件裡不寫死字型。

- 只有一套字級比例；標題 `text-wrap: balance`，內文行寬約 38em。

## 3. 三語

做任何設計，都要放三語的**實際字串**去看。

- **每個區塊三語只有一個名字**，一個 i18n key 對一個名字，nav、頁標題、首頁、時間線都用同一個：

  | key | 中 | EN | 日 |
  |---|---|---|---|
  | posts | 文章 | Posts | 記事 |
  | journal | 日記 | Journal | 日記 |
  | topics | 專欄 | Topics | コラム |
  | thoughts | 想法 | Thoughts | つぶやき |
  | timeline | 時光 | Timeline | タイムライン |
  | friends | 友鏈 | Friends | 友リンク |

  現在混用的「筆記／手記」「碎念」「時間線」都收進上表（中文的時間線叫「時光」，2026-11-02 站主定）。頁面標題不寫死中文。
- 標籤不靠單一個漢字（「尋」改成「搜尋／Search／検索」）。
- **節氣、候名三語都用漢字**，這是站的個性；周圍的說明照常翻譯（「10 days until 立冬」）。
- **沒翻譯的內容照實說**：列表上一個小標（In Chinese／中国語），內頁開頭一行說明。
- 英文字串通常比中文長兩三倍，nav、按鈕、footer 都要用英文測過。
- 日期、數字用 `Intl` 依語系格式化。

## 4. 進站開場

- 直接用現在的 `components/ink-intro.tsx` ＋ `lib/ink-fluid.ts`：節氣名 → 墨面蓋滿、三滴墨落下暈開 → 被水沖淡、露出網站。
- 互動：游標滑過攪動墨流。一按、一捲、一按鍵就跳過。
- 每次整頁載入都播，站內換頁不播。減少動態效果時不播。

## 5. 首頁

首屏不高（約七成畫面）。左邊：名字「唯一」（一般標題大小）、兩行標語、一排社群連結的細線圖示；**社群連結那一行的底就是水線**。右邊：一座水墨鳥居站在水線上，用朱一筆一筆畫（笠木 → 島木 → 柱 → 貫 → 額束），開場的墨退掉後才畫出來。首屏最下面是目前節氣與候（漢字）；首屏以下是一封信與円相（見下面「首屏以下」）。

首頁有三種模式，讀者在 footer 切換：

| 模式 | 畫面 | 互動 |
|---|---|---|
| **筆跡**（預設，2026-11-03 起） | 首屏是一張紙：鳥居站在紙上，水線下有鳥居與社群圖示的倒影（跟水面同一份，鳥居畫完才浮出來、慢慢晃；不跟筆互動），但沒有水紋、墨池、漣漪。鳥居畫完後，網站自己在水線上寫一橫（起筆慢、中段快、收筆慢）再乾掉，示範這張紙可以寫；寫完提示字與顏料才淡入 | 游標就是筆，見下面「筆跡」 |
| **水面** | 水線以下是水：鳥居與社群圖示的倒影（一條一條橫向錯開地晃，鳥居畫完才浮出來），往下幾道很淡、慢慢起伏的水紋。開場的墨退掉後，在水面上再落一滴，接上開場 | 點水面滴一滴墨（墨在水裡化開成墨流的紋，幾秒內淡掉），點的地方泛出扁的漣漪，漣漪經過倒影時倒影晃得更大；游標滑過攪動墨流 |
| **素面** | 只有字（名字、標語、社群圖示、節氣），沒有鳥居、沒有任何畫 | 無 |

- 水面用同一支 `ink-fluid`，加兩個能力：不蓋墨面的持續模式（`pool`）、在某一點滴墨（`drop`）。沒有墨面蓋著時只有墨流的邊緣顯色，所以水面用的邊緣濃度比開場高；夜裡用淡墨色，不用節氣色的微光。
- 模式存在讀者自己的瀏覽器（localStorage），存不了就用預設的筆跡。footer 的順序是 筆跡｜水面｜素面。
- 減少動態效果時：筆跡照常（墨只跟著讀者的手出現），但不寫示範的那一橫、鳥居直接是畫好的；選水面的換成素面（水面會自己動）。選水面但不支援 WebGL2 時也退回素面（筆跡只用 2D 畫布，不受影響）。

**筆跡**（`(home)/-components/brush-surface.tsx`，2026-11-03 重做）：
- 一支筆是一排筆毛（最多 12 根），每根是沿著筆畫蓋過去的小墨點。墨飽時疊成實的一道，邊上的點微微錯開，邊緣是毛的、不是平滑的管子。
- 越慢越粗（1.6–16px），數位筆再乘上筆壓；起筆一團飽墨、略頓，提筆收尖。
- 飛白是筆毛乾掉：蘸一次墨大約寫 1500px，越寫越乾，寫快了也乾；乾掉的地方是沿著筆畫一段一段的長條，邊上的筆毛先乾。墨用掉的那一份最多讓筆毛乾到一半：寫再長只是飛白多，不會整筆斷掉（2026-11-04：有人簽名簽到一半就沒了）。一筆最多 3000 點。
- 墨剛落下的前 0.9 秒邊緣暈開一圈淡的；乾是往紙色混過去（不透明），不是變透明。**自己的筆停筆 1.2 秒後才開始乾**，約兩秒半乾掉（簽名、寫字寫好幾筆，寫完前不會先乾掉前面的）；別人的筆照落下的時間乾。
- **按著拖曳才寫**，放開就收筆（滑鼠是左鍵；2026-11-03 站主改的：滑過就寫沒辦法好好畫）。
- **整個首頁都是紙**（2026-11-04 站主要的）：畫布從頁首後面一路蓋到首頁最底（首屏以下的信與円相也寫得上去），蓋在內容上面但不吃滑鼠，事件從首頁那一層收；從連結、按鈕、輸入框上按下去照常點、不寫。滑鼠按著拖曳是寫字，不選字。
- 觸控：橫著拖曳馬上寫；**按住不動 0.24 秒再畫**，往哪個方向都行；直接直著滑是捲動（這一塊 `touch-action: pan-y`，瀏覽器拿去捲動時送 `pointercancel`，先收著沒畫的那一筆就丟掉；拿起筆之後 `touchmove` 擋掉捲動）。所以手機上首屏不用變矮。
- **顏料**（2026-11-03 站主加，同日再加綠與咖啡色好畫植物；元素預算見第 0 節）：照國畫的用法排——墨、赭墨（赭石調墨：枝幹）、赭石、藤黃、汁綠（花青調藤黃：葉）、石綠（礦物綠：苔、嫩葉）、花青、朱。三語：Ink／Umber／Ochre／Gamboge／Sap green／Malachite／Indigo／Vermilion；日文 墨／赭墨／代赭／藤黄／汁緑／石緑／花青／朱。token 是 `--foreground`、`--pigment-*`、`--zhu`（styles.css，彩度壓低像紙上的顏料，夜裡提亮）。只給首頁的筆用，不進一般 UI。在首屏右下提示字旁邊一排小色點選（選中的外面一圈 `--ink-3` 細線），存在讀者的瀏覽器（`brush-pigment.ts`），存不了就用墨。示範的那一橫一律用墨。
- **橡皮擦**（2026-11-03 站主要的）：登入的人在色點最後多一個橡皮擦圖示（tabler `eraser`，選中是 `--ink-1`）。按著拖過去，碰到的**自己的**乾痕（還有自己還沒乾的筆）就拿掉，放開時告訴伺服器（`homeInk.eraseMine`，只刪得到自己今天的，墨還回去）；正在看的人那邊也跟著消失。擦不到別人的。選顏料就換回筆；不存，每次進首頁都是筆。
- **大家一起寫**（2026-11-03 站主要的）：
  - 同時在首頁的人看得到彼此正在寫的筆（晚約 0.15 秒、照原本的速度畫出來，濃度是自己的八成），看不出是誰寫的。
  - **登入的人**寫的才送出去；乾了以後留一層**乾痕**在紙上，到台北時間當天結束（每天 0 點換一張紙）。**匿名的人**只在自己的畫面上寫、不送出去，乾了就沒了、不留乾痕（2026-11-04 站主定：要留在紙上就得登入），提示那一行多一句「登入後寫的，會留在紙上到今天結束」。
  - 乾痕全部畫在同一張畫布上（實色），整張用 40% 的濃度疊上去（2026-11-04 從 16% 調濃：太淡看不出來）：再多筆疊在一起也不會比這更黑。首屏以鳥居高的四分之一切格，一格的墨滿了，壓在那格的舊筆就不畫（新的優先）；紙上最多留最新的 800 筆。
  - 座標以鳥居為準（柱腳中間是原點、鳥居高是 1），不同大小的畫面筆跡都落在鳥居旁的同一處。
  - 每個人一天一池墨（大約幾十個簽名；朱寫起來三倍費墨；收筆那一段沒送到會再送一次，不然整筆不會存）；用完了提示換成「今天的墨用完了，再寫只有你看得到」。
  - 後台可以看今天的紙、擦掉一筆、擦掉某個人今天寫的全部（`admin.homeInk`）；擦掉時正在看的人那邊也跟著消失。
- 水面的 WebGL 在載入完成、主執行緒空閒後才建立（`lib/after-load.ts` 的 `afterLoadIdle`），離開首頁或分頁不可見時暫停並釋放。

**首屏以下：一封信與円相**（2026-11-03 站主定案）。不排「區塊標題＋列表」；寬版左信右圓，窄版信在上、圓在下：
- **信**（`(home)/-components/home-letter.tsx`）：大字「你好，」，接三句，每句一段，句子由現有資料組成，沒有的那句就不寫：
  - 這個節氣寫了哪幾篇（最多列三篇，多了寫「寫了 N 篇，最近的是…」）；這個節氣還沒寫就照實說「霜降以來還沒寫新的。上一篇是秋分的時候寫的《…》」。
  - 最近在想：最新一則想法的第一句（四個月內才寫）。
  - 上一封來信：最新一則公開留言（審核通過、在文章或日記下、不是站主的；半年內才寫），寫留言的人、在哪一篇、第一句。
  - 篇名、想法、留言都嵌在句子裡，底下一條淡墨線，滑過轉朱、點了去那一頁。節氣用朱。句型在三語 messages 裡（`home_letter_*`），語序各語系自己定，篇名用 `Intl.ListFormat` 接起來；元件用記號嵌進翻好的句子（`-components/rich.tsx`）。不放自動長出來的感想句。
  - 信末是文章頁的落款與名印（`LetterSignature`），最下面一行「全部文章 →　想法 →」，上面一條 `--ink-5` 髮絲線。
- **円相**（`(home)/-components/enso.tsx`）：時光頁乾筆線的筆法寫成一個圓。一圈從立春起算（干支也在立春換年，跟落款同一年），立春在左上、順時針；一個節氣一段，那個節氣寫得多（文章、日記、想法都算）就飽黑粗，沒寫只剩乾筆與飛白，濃淡在節氣開頭慢慢換過去。起筆藏鋒，寫到今天收尖，今天到明年立春是缺口。寫到今天的那一段用朱。四立用漢字標在圓外（`--ink-3`），每篇文章、日記一個「、」落在圓外（同一天的往外疊），滑過或鍵盤移到時圓心換成那個節氣、篇名、日期。圓心平常是「今年已寫 N 篇／目前在 霜降」與「時光 →」。捲到才照順序寫出來（約 2.4 秒一整圈），點在筆經過時落下；減少動態效果直接是寫好的。筆畫座標以小時取整，伺服器與瀏覽器畫的一樣。
- 資料都在 `home.getHome`：`timeline.items`（全部文章、日記）、`musings`、`letters`（含 `ref` 那一篇的標題與連結）、`thoughtDates`（約 13 個月內想法的日期，只給円相算墨）。
- 試過不要的：編號近期文章、地球、技能跑馬燈（像 innei）；障子曆；兩欄「最近的文章／日記」（太單調）；頭條放大；一條橫軸上排圓點或熱力格式的寫作圖表。

## 6. nav 與 footer

  - 所在的區名寫在墨點左邊（`font-display`、`--ink-2`，滑過轉朱、點了回那一區的首頁；首頁不寫；打開選單時淡掉讓給選單），各區首頁的標題就是它（2026-11-02 站主定）。

  - 第一欄只有各區：首頁、文章、日記、想法、時間線、友鏈（專欄併進日記、朋友圈併進友鏈）。所在那一區是朱色。

## 7. 換頁：墨洇

### 方向

| 深度 | 頁面 |
|---|---|
| 1 | nav 第一欄的各區：首頁、文章、日記、想法、時間線、友鏈 |
| 2 | 子列表（nav 的第二欄）：`/categories`、`/categories/$slug`、`/notes/topics`、`/notes/topics/$slug`、`/fcircle` |
| 3 | 內頁：`/posts/$slug`、`/notes/$id` |

- **同一深度之間 → 橫向**。方向照 nav 的順序：往右邊的區塊，字往左走。內頁之間的上一篇／下一篇也是橫向：下一篇往左、上一篇往右。
- **往深處 → 字往下落**；**回淺處 → 字往上**。
- 每一頁都要有轉場，沒有硬切的頁。

### 做法

| 階段 | 做法 | 數值 |
|---|---|---|
| 舊頁 | 像被水打濕：暈開、淡掉，順著方向微移 | 200ms，ease-in；blur 0 → 5px、opacity 1 → 0；橫移 10px／上下 6px |
| 新頁 | 從暈開的墨收乾變清楚，順著方向移入，標題先出、各行錯開 | 每行 340ms、ease-out；blur 4px → 0、opacity 0 → 1；橫移 12px／上下 6px；從 110ms 起每行錯開 24ms，第 9 行以後一起出 |
| 錨字 | 列表 ⇄ 內頁時，被點的那個標題不暈，直接移到新的位置 | 480ms，`cubic-bezier(0.6, 0, 0.2, 1)` |
| 篩選、分頁、切語系 | 只淡入 | — |

- 整次換頁約 0.6 秒，但**不擋操作**：資料先載好才開始；一捲、一按鍵、再點一次就直接跳到結果（含上一頁／下一頁鍵）。
- 不蓋任何全螢幕疊層，只有字在動。
- 模糊濾鏡有成本：同時暈的行數最多 9 行；低階裝置（`deviceMemory` < 4、CPU 核心 < 4、觸控＋短邊 < 640px 的手機）只淡入、位移，不模糊。
- 錨字的新舊兩張不交疊：列表的小字先淡掉（200ms），內頁的大字從 110ms 起浮出（340ms）。
- 實作：方向 `lib/page-depth.ts`、換頁 `lib/page-transition.ts`、新頁的行 `lib/page-enter.ts`、CSS 是 styles.css「墨洇」。
- 不截圖、直接是活畫面的層：header（`site-header`）、導覽的墨（`nav-ink`）、日記內頁左邊的清單（`note-rail`，清單自己有 framer 動畫，站主調過，不能被截圖蓋住）。
- 減少動態效果：拿掉模糊、位移和錨字移位，只淡入淡出（150／200ms）。

### 動態 token

| token | 值 |
|---|---|
| `--dur-out` | 200ms |
| `--dur-in` | 340ms |
| `--dur-move` | 480ms |
| `--stagger` | 24ms |
| `--ease-out` | `cubic-bezier(0.2, 0.7, 0.2, 1)` |
| `--ease-move` | `cubic-bezier(0.6, 0, 0.2, 1)` |

framer-motion 的 spring 也要對齊這套，不另開彈性曲線。

## 10. 參考其他站的分寸

可以參考別人的站（例如 koimsurai「宙と木」），但**做出來不要太像**：
- 可以學方法：先定規則再寫程式、每頁回答同一個問題、轉場由一層統一負責、邊界情況寫清楚、每個語系各配字型。
- 不學招牌做法：星空、點與線、單一琥珀點、整頁收成一點再飛到下一頁長出來的轉場、把每篇文章畫成背景裡的物件。
- 新增設計時先問：拿掉配色與題材之後，這個做法是不是跟某個參考站一樣？是的話就換一個。
