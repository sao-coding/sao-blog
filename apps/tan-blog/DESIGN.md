# 影の書庫 · 設計風格指南

新增頁面、元件、動畫之前先讀這份。文章內的區塊元件另有細則：[`src/components/mdx/DESIGN.md`](src/components/mdx/DESIGN.md)（「紙上之物」）。

## 一句話

**水墨與和紙之間的一間書庫**：中國水墨山水的墨韻與節氣，加上日本的鳥居、和紙、留白與「間」。
晝是一張四季信箋，夜是燈影下的夜讀。安靜、手作、有季節感，不炫技。

## 1. 世界觀：中與和的分工

兩種風格不平均混合，而是各管一層，避免變成「什麼都放」的拼貼：

| 層 | 主導 | 元素 |
|---|---|---|
| 結構與時間 | 中 | 二十四節氣、水墨山水、墨暈、手卷（展卷／收卷）、信箋與朱色文武線 |
| 留白與界線 | 和 | 鳥居（入口與分界）、和紙纖維、障子格、「間」——大量留白與停頓 |
| 點綴 | 共用 | 朱色（中國的印泥／日本的鳥居同一個朱）、燈籠、月 |

- **朱色是兩種文化的交集**，也是全站唯一的強調色（`--ink` / `--zhu`）。鳥居、印記、強調一律用它，不另開紅色。
- 鳥居象徵「從俗世進入另一處」：用在**入口與分界**——進站開場、區塊切換、頁尾、404，不拿來當裝飾花紋重複貼。
- 日式元素用**線與留白**表現（細線鳥居剪影、障子格線、和紙纖維），不用浮世繪、櫻花滿版、和柄花紋大面積鋪底。
- 不使用印章作為主要視覺（太常見、不夠新）。

## 2. 顏色

- 全部用主題 token，不寫 Tailwind 原色：墨 `--foreground`、紙 `--background` / `--card`、朱 `--ink`、玉 `--jade`、髮絲線 `--rule`。
- **節氣色 `--season`**：由 `lib/term-themes.ts` 依目前節氣提供（24 個），是「季節的那一抹」，只用在點綴（進度條、霧與月暈的染色、小標記），不用在大面積底色。
- 晝夜兩套：晝＝宣紙（淺、暖、低彩度）；夜＝「夜讀」（深藍黑、星點、燈籠暖光）。新元件兩套都要看過。
- 冬天的節氣色接近白色：任何用 `--season` 鋪面的設計都要在冬至檢查一次。

## 3. 字

- 標題、人話：霞鶩文楷 TC（`font-wenkai`）。技術資訊：mono。
- 中文不加粗表現強調，用朱色或字距；大標可用直排（`writing-mode: vertical-rl`）營造書卷感。

## 4. 紙與線

- 層次靠「紙色上加幾 % 墨」與 1px 髮絲線，不靠粗框與陰影；陰影只給真的浮起的東西（相片、信紙疊層）。
- 紙紋（宣紙/和紙纖維）以 SVG feTurbulence 生成並 `multiply`；長頁面注意效能（見 letter-paper 的毛邊做法）。

## 5. 動態：「間」的節奏

依頻率決定強度——越常發生越輕：

| 時機 | 做法 | 實作 |
|---|---|---|
| 整頁載入（重新整理／從外部進站） | 墨暈開場：節氣名 → 墨滴落下 → 被水沖淡 | `components/ink-intro.tsx`、`lib/ink-fluid.ts` |
| 首頁主視覺 | 3D 夜航水墨山水（烏篷船、燈籠倒影），只留水面互動（滑過水紋、點擊漣漪） | `components/ink-voyage.ts` |
| 文章列表 ⇄ 文章 | 展卷／收卷（View Transitions：標題飛行＋由上展開） | `lib/post-transitions.ts`、styles.css「展卷」 |
| 文章之間 | 翻頁 | 同上 |
| 換頁慢於 300ms | 頂端節氣色毛筆一筆 | `components/ink-progress.tsx` |
| 其他站內換頁 | 不做轉場 | — |

規則：
- 一般過場 150–300ms、ease-out；儀式性動畫（開場、展卷）可到 0.6–1s，但**不可阻擋操作**——使用者一碰螢幕或捲動就直接跳到結果。
- 互動要克制：一個場景最多一兩種，且必須跟主題相關（水面漣漪 ✓，滿天亂飛的粒子 ✗）。
- `prefers-reduced-motion: reduce`：關掉所有位移動畫與開場。
- 3D / WebGL 一律在載入完成、主執行緒空閒後才建立（`afterLoadIdle`），不可見時暫停，結束時釋放並移除 canvas。

## 6. 季節

- 季節以二十四節氣劃分（`lib/season.ts`），一律以站主時區計算。
- 四季的山水設色：春「青綠」、夏「濃墨」、秋「淺絳」、冬「雪景」；白露／寒露／霜降霧較濃。
- 物候飄落物（梅、櫻、油桐、鳳凰花、欒樹、楓、雪……）只出現在首頁主視覺。

## 7. 鳥居與和風元素：用法草案（待實作）

- **進站開場**：墨暈沖淡時，遠景浮現一座細線鳥居剪影，穿過它才進入網站。
- **首頁山水**：江岸或水中立一座朱色鳥居（像嚴島神社的水中鳥居），是畫面唯一的高彩度物件，夜裡燈籠映在它身上。
- **區塊分隔**：大段落之間可用極細的鳥居線條（笠木＋島木的兩道橫線）當分隔符號，取代一般的 `<hr>`。
- **404**：迷路的鳥居（一座通往霧裡的鳥居）。
- 數量原則：一個畫面最多一座鳥居。
